# Barbershop Booking

Учебный проект по дисциплине «Программная инженерия»: веб-сервис онлайн-записи в барбершоп.

## Назначение

Сервис помогает клиенту выбрать услугу, барбера и свободное время, а барберу и администратору — управлять расписанием и записями.

Подробный паспорт проекта находится в [docs/00-project.md](docs/00-project.md).

## Технологический стек

- Java 21
- Spring Boot 3.3.5
- Spring Web, Spring Data JPA, Bean Validation
- PostgreSQL 16.4
- Maven
- Docker Compose

## Запуск

Предварительно установите Docker Desktop и убедитесь, что команды `docker` и `docker compose` доступны в терминале.

Из корня проекта выполните:

```bash
docker compose up --build
```

При первом запуске Docker скачает образы и соберёт приложение. Остановка выполняется командой:

```bash
docker compose down
```

## Проверка работоспособности

1. Дождитесь сообщения о запуске Spring Boot.
2. Откройте <http://localhost:8080/api/health>.
3. В ответе должен появиться JSON со значением `"status":"ok"`.

Проверка из терминала:

```bash
curl http://localhost:8080/api/health
```
